# Frontend Mentor - Four Card Feature Section

This is my solution to the **Four Card Feature Section** challenge from [Frontend Mentor](https://www.frontendmentor.io/).

The goal of this challenge was to build a responsive feature section using HTML and CSS, following the provided design and adapting the layout for desktop and mobile screen sizes.

## 📸 Preview

![Four Card Feature Section](./design/desktop-preview.jpg)

## 🚀 Built With

* HTML5
* CSS3
* CSS Grid
* Flexbox
* Media Queries
* Responsive Design
* Google Fonts

## 🎨 Features

The project includes:

* Responsive layout for desktop and mobile devices.
* Four feature cards with individual accent colors.
* CSS Grid for the desktop three-column layout.
* Single-column layout for mobile devices.
* Responsive typography using `clamp()`.
* CSS custom properties for color management.
* Poppins font with weights 200, 400 and 600.
* Semantic HTML structure.

## 🖥️ Desktop Layout

On larger screens, the cards are arranged in three columns:

* **Supervisor** on the left.
* **Team Builder** and **Karma** in the center.
* **Calculator** on the right.

The cards on the left and right are vertically centered relative to the two cards in the middle.

## 📱 Mobile Layout

On smaller screens, the layout changes to a single column.

The four cards are displayed vertically, with a maximum width to prevent them from occupying the entire screen.

The layout maintains spacing between the cards and the edges of the viewport.
